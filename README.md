# تأثیر داده‌ی باز — روایت فارسی

سایتی ایستا، فارسی و راست‌چین که **۳۷ مطالعه‌ی موردی** پروژه‌ی
[Open Data’s Impact](https://odimpact.org) (گاورلب دانشگاه نیویورک) را به شکلی
خوانا روی وب منتشر می‌کند: از نبرد با ابولا در سیرالئون تا اقتصاد جی‌پی‌اس،
و نمونه‌هایی که در آن‌ها داده‌ی باز نتیجه‌ی معکوس داد.

کنار آن سه بخش دیگر هم هست که تجربه‌ی جهانی را به زمینه‌ی ایران وصل می‌کند:
**۹ گزارش فارسی** (تألیفی و ترجمه‌ای)، فهرست **۶۶ مفاد قانونی ایران** درباره‌ی
دسترسی آزاد به اطلاعات، و کتاب‌شناسیِ **۱۶۰ منبع** پژوهشی. بخش چهارم،
**زیست‌بوم داده در ایران**، کنشگرانی را معرفی می‌کند که داده‌ی عمومی را به خدمت
تبدیل کرده‌اند (نخستین: رسمیو)؛ فقط توضیح می‌دهد، خودِ داده را منتشر نمی‌کند.

صفحه‌ی اول با یک **ویدئوی معرفی ۸۳ ثانیه‌ای** باز می‌شود که با
[Remotion](https://www.remotion.dev) ساخته شده و با Remotion Player همان‌جا در
مرورگر پخش می‌شود؛ فارسی، راست‌به‌چپ و با نوار زمان فصل‌بندی‌شده برای ارائه.

## در یک نگاه

HTML و CSS و جاوااسکریپتِ ساده که از روی JSONِ ساختاریافته تولید می‌شود —
بدون هیچ مرحله‌ی بیلدی هنگام انتشار. تنها کد فریم‌ورکی، پلیر ویدئوی صفحه‌ی اول
(React و Remotion) است که از قبل در یک فایل (`site/assets/js/showreel.js`) بسته
شده و فقط در صفحه‌ی اول بار می‌شود.

## ساختار مخزن

```
build/
  catalog.py          فراداده‌ی دستی هر مطالعه (عنوان، زیرعنوان، کشور، دسته، سال)
  parse.py            استخراج مطالعات موردی از ورد        →  data/cases.json
  catalog_reports.py  فراداده‌ی دستی ۹ گزارش فارسی
  parse_reports.py    استخراج گزارش‌ها از ورد              →  data/reports.json
  parse_laws.py       استخراج فهرست قوانین از PDF          →  data/laws.json
  parse_library.py    ساخت کتاب‌شناسی از PDF/RIS           →  data/library.json
  site.py             تولید همه‌ی صفحه‌های HTML             →  site/
data/
  cases.json       ۳۷ مطالعه‌ی موردی (خلاصه، نکات کلیدی، بخش‌ها، شکل‌ها)
  reports.json     ۹ گزارش فارسی (بخش‌ها، جدول‌ها، جعبه‌ها، شکل‌ها، منبع و حق نشر)
  laws.json        ۶۶ مفاد قانونی (شماره، تاریخ، مأخذ، عنوان، متن)
  library.json     ۱۵۸ منبع پژوهشی (عنوان، نویسنده، سال، ناشر، DOI/نشانی)
  ecosystem.json   کنشگران زیست‌بوم داده‌ی ایران (دستی؛ هیچ تجزیه‌گری روی آن نمی‌نویسد).
                   منبع‌های کتاب‌شناختی‌شان هنگام ساخت به کتابخانه افزوده می‌شود
  highlights.json  روایت‌های عددی و نمونه‌های هر بُعد (دستی؛ برای صفحه‌ی اول و ویدئو)
  world.json       نقشه‌ی نقطه‌ای جهان و جای ۲۵ کشور (تولیدشده)
video/          ویدئوی معرفی با Remotion و پلیر صفحه‌ی اول
  src/scenes/        نُه صحنه‌ی ویدئو (صحنه‌ی «رسمیو» متن و عددهایش را از data/ecosystem.json می‌خواند)
  src/player/        پلیر و کنترل‌های راست‌به‌چپ        →  site/assets/js/showreel.js
  scripts/gen-data.mjs   نقشه و داده‌ی سبک ویدئو          →  data/world.json، site/assets/img/world-dots.svg
site/           خروجی قابل انتشار — همین پوشه روی GitHub Pages سرو می‌شود
```

> **فایل‌های منبع در مخزن نیستند.** پارسرها یک‌بار روی یک آرشیو محلی اجرا شده‌اند و
> خروجی‌شان (`data/*.json` و تصاویر `site/assets/img/`) همان چیزی است که سایت از آن
> ساخته می‌شود. برای اجرای دوباره‌ی پارسرها باید مسیر آرشیو را در `ODFA_SRC` بدهید.

## بازتولید سایت

برای بازسازی HTML فقط به `data/*.json` نیاز است:

```bash
python3 build/site.py          # بازسازی صفحه‌ها از روی داده‌ی موجود
python3 -m http.server 4173 --directory site
```

برای استخراج دوباره از فایل‌های منبع (نیازمند `lxml`، `Pillow` و `pymupdf`)،
مسیر آرشیو را بدهید:

```bash
ODFA_SRC=/path/to/archive python3 build/parse_reports.py
ODFA_SRC=/path/to/archive python3 build/parse_laws.py
ODFA_SRC=/path/to/archive python3 build/parse_library.py
python3 build/site.py
```

سایت روی گیت‌هاب‌پیجزِ یک مخزن پروژه سرو می‌شود، پس صفحه‌ی ۴۰۴ نشانی مطلق
`/odimpact-fa/` می‌گیرد. اگر دامنه‌ی اختصاصی تنظیم کردید، با
`ODFA_BASE=/ python3 build/site.py` بسازید.

## ویدئوی معرفی

ویدئو یک ترکیب Remotion (۱۹۲۰×۱۰۸۰، ۳۰ فریم در ثانیه، ۲۱۴۶ فریم) در
`video/src/Showreel.tsx` است: پرسش آغاز، معرفی، آمار، نقشه‌ی ۲۵ کشور، چهار بُعد
تأثیر، شش روایت عددی، پل به ایران و پایان. در صفحه‌ی اول همین ترکیب با
`@remotion/player` زنده در مرورگر ساخته می‌شود (فایل ویدئویی دانلود نمی‌شود) و
بی‌صدا، وقتی دیده شود، خودکار پخش می‌شود.

**راست‌به‌چپ:** متن‌ها واژه‌به‌واژه و از راست ظاهر می‌شوند (حرف‌به‌حرف کردن، اتصال
حروف فارسی را می‌شکند)، صحنه‌ی بعد از چپ وارد می‌شود، نوارهای پیشرفت از راست پر
می‌شوند، سنجاق‌های نقشه از شرق به غرب روشن می‌شوند و همه‌ی عددها فارسی‌اند.
نوار زمان پلیر هم فصل‌بندی‌شده است و از راست به چپ پیش می‌رود.

**برای ارائه:** دکمه‌ی «تماشای ویدئو در حالت ارائه» ویدئو را از ابتدا و تمام‌صفحه
پخش می‌کند. وقتی پلیر فعال است (رویش کلیک کنید):

| کلید | کار |
|---|---|
| `Space` یا `K` | پخش / توقف |
| `←` / `PageDown` | فصل بعد (نوار زمان راست‌به‌چپ است) |
| `→` / `PageUp` | فصل قبل یا ابتدای همین فصل |
| `۱` تا `۸` | پرش به فصل |
| `F` | تمام‌صفحه |

نسخه‌ی MP4 برای پخش بیرون از سایت (مثلاً در اسلاید یا روی سیستم بی‌اینترنت) را
خودتان بسازید؛ در مخزن ثبت نمی‌شود:

```bash
cd video
npm ci
npm run studio     # پیش‌نمایش و ویرایش صحنه‌ها
npm run build      # بازسازی data/world.json و site/assets/js/showreel.js
npm run poster     # پوستر پلیر → site/assets/img/showreel-poster.jpg
npm run render     # MP4 → video/out/odimpact-fa-showreel.mp4
```

اگر Chrome Headless Shell از قبل نصب است، مسیرش را در `REMOTION_BROWSER` بدهید تا
Remotion آن را دوباره دانلود نکند. هر عدد ویدئو از `data/*.json` می‌آید؛ متن
روایت‌های عددی در `data/highlights.json` است و صفحه‌ی اول هم از همان می‌خواند.
پس از تغییر آن، هم `npm run build` و هم `python3 build/site.py` را اجرا کنید.

## طراحی

- قلم **یکان بخ** (وزن‌های Light تا Black، فرمت `woff2`)
- راست‌چین کامل، حالت روشن/تاریک، واکنش‌گرا
- رنگ اختصاصی برای هر بُعد تأثیر؛ هر کارت گرادیان و بافت منحصربه‌فرد خود را از
  روی `slug` می‌سازد
- نقشه‌ی مکان‌نمای هر کشور به‌صورت خودکار از فایل ورد تشخیص داده و به شبح شفاف
  تبدیل می‌شود
- فهرست مطالب چسبان، نوار پیشرفت مطالعه، لایت‌باکس تصاویر، جست‌وجوی زنده
- صفحه‌ی اول: قهرمان سینمایی با ویدئو، شمارنده‌های متحرک، نوار روان عنوان‌ها،
  نقشه‌ی تعاملی کشورها، ابعاد تأثیر، کارت‌های شواهد و پل تجربه‌ی جهانی به ایران
- با «کاهش حرکت» سیستم‌عامل، انیمیشن‌ها و پخش خودکار خاموش می‌شوند

## حق مؤلف و مجوزها

- **متن مطالعات موردی** متعلق به [The GovLab](https://thegovlab.org) دانشگاه
  نیویورک است و در [odimpact.org](https://odimpact.org) منتشر شده. این مخزن
  صرفاً روایت فارسی و غیرتجاری آن است.
- **قلم یکان بخ** نرم‌افزاری مالکیتی از [فونت ایران](https://fontiran.com) است.
  فایل‌های وب‌فونت طبق شرایط ناشر همراه با `site/assets/fonts/FontLicense.txt`
  عرضه شده‌اند؛ **کد لایسنس خود را در آن فایل درج کنید**. اگر مجوز انتشار وب
  ندارید، فایل‌های `woff2` را از مخزن حذف و قلم دیگری جایگزین کنید.
- **گزارش‌های فارسی** تألیف یا ویرایش نویسندگان همین مجموعه‌اند؛ آن‌هایی که بر پایه‌ی
  سند دیگری نوشته یا ترجمه شده‌اند، منبعشان در پایان هر گزارش آمده است (از جمله
  منشور بین‌المللی داده‌ی باز که با پروانه‌ی CC BY منتشر شده).
- **متن قوانین** از قوانین موضوعه‌ی کشور است و به‌صورت خودکار از
  `site/assets/docs/قوانین-داده-باز-ایران.pdf` استخراج شده؛ برای استناد حقوقی به
  متن رسمی مراجعه کنید.
- **کتابخانه‌ی منابع** فقط فهرست کتاب‌شناختی است؛ هیچ فایلی از آثار دیگران در این
  مخزن منتشر نشده است.
- **کد** (`build/`, `video/`, `site/assets/css`, `site/assets/js`) تحت مجوز MIT است.
- **Remotion** (پلیر و ابزار ساخت ویدئو) مجوز اختصاصی خود را دارد: برای افراد،
  سازمان‌های غیرانتفاعی و شرکت‌های انتفاعی تا سه نفر رایگان است و شرکت‌های بزرگ‌تر
  باید [مجوز شرکتی](https://www.remotion.pro/license) بگیرند
  (متن کامل: `video/node_modules/remotion/LICENSE.md`).
- **نقشه‌ی جهان** از داده‌ی [Natural Earth](https://www.naturalearthdata.com)
  (مالکیت عمومی) و بسته‌ی `world-atlas` ساخته شده است.
